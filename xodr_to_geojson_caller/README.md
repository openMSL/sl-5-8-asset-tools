# xodr_to_geojson_caller

## Description
Calls the VCS `opendriveconverter` Java tool to convert OpenDRIVE into GeoJSON.

## Usage
```bash
python -m xodr_to_geojson_caller.main <file.xodr> -out <output.geojson> -path <temp_dir>
```

## Arguments
- `filename` (required): OpenDRIVE input file.
- `-out` (required): Output GeoJSON file path.
- `-path` (required): Temporary working directory path.

## Input
- OpenDRIVE file

## Output
- GeoJSON output generated by converter tool

## Install
```bash
make install  # from repository root
```

## Notes
- Requires Java runtime and converter JAR setup.
- This module is disabled in the default pipeline configuration.
